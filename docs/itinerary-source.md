# 🇯🇵 日本福岡六日行程｜2026/12/12～12/17

📍 **住宿點：博多站周邊**
✈️ **去程：12/12（六）08:00 - 11:15 抵達福岡**
✈️ **回程：12/17（四）12:15 - 13:50 返回台灣**

---

## 📝 12/12（星期六）Day 1：抵達福岡、JR Pass 兌換、咖啡甜點、運河城與地雞炭火燒

* **11:15 - 12:30｜抵達福岡、入境、領行李**
  * **行程**：
    * 抵達福岡機場國際線後，辦理入境、領取行李、通過海關。
    * 通過海關後進入 **福岡機場國際線航廈 1F 到達大廳**。
  * **⚠️ 注意**：
    * 先不要直接去搭巴士。
    * 領完行李、通過海關後，先處理 **JR 北九州鐵路周遊券兌換**。

* **12:30 - 12:50｜福岡機場兌換 JR 北九州 Pass ＆ 領取指定席券**
  * **地點**：
    * 福岡機場 **國際線航廈 1F 到達大廳**
    * **JR KYUSHU RAIL PASS Exchange Counter**
  * **行程**：
    * 兌換 **JR 北九州鐵路周遊券 3 日券**。
    * 指定 Pass 啟用日為：
      * **2026/12/13（日）**
      * 有效期間：**12/13～12/15，共連續 3 天**。
    * 領取已在線上預約的 **12/14 由布院之森指定席券**。
    * 領取／確認 **12/14 由布院 → 博多回程指定席券**。
    * 若現場可辦理，也可詢問是否能一併處理 **12/13 博多 ⇄ 小倉 Sonic 指定席**。
      * 若想保留行程彈性，也可以不劃 Sonic 指定席，當天視班次搭乘自由席。
  * **必帶**：
    * 護照。
    * Klook／JR Pass 電子兌換憑證或 QR Code。
    * 由布院之森線上劃位確認信／QR Code。
    * 預約時使用的信用卡。
    * 手機截圖備份。
  * **⚠️ 注意**：
    * 每位 JR Pass 使用者本人都要攜帶護照辦理。
    * **12/12 當天只是提前領取 Pass，不代表當天開始計算效期。**
    * 記得明確告知櫃台：
      * **Start date：December 13, 2026**
    * **博多 ⇄ 小倉不要搭山陽新幹線**，JR 北九州 Pass 不適用該區間的新幹線。

* **12:50 - 13:30｜福岡機場 → 博多站**
  * **交通**：
    * 辦完 JR Pass 後，跟著 **「Bus／バス」** 指標前往出口。
    * 前往福岡機場國際線巴士乘車處。
    * 搭乘往 **「博多駅／Hakata Station」** 的 Airport Bus。
    * → **博多駅（筑紫口）**
  * **車程**：
    * 車程最快約 **15 分鐘**。
    * 考量等車及路況，建議抓約 **20～30 分鐘**。
  * **⚠️ 注意**：
    * 不用搭免費接駁巴士前往國內線。
    * 不用轉搭地下鐵。
    * 上車前再次確認車頭／站牌顯示 **「博多駅」**。
  * **付款提醒**：
    * 可準備 Suica／ICOCA／nimoca 等交通 IC 卡或現場可使用的付款方式。

* **13:30 - 13:45｜博多站 → 飯店寄放行李**
  * **交通**：
    * 博多站筑紫口 → **東急 Stay 博多**
    * 步行約 **7～10 分鐘**。
  * **行程**：
    * 抵達飯店後先寄放行李。
    * 不用正式 Check-in，先輕裝開始第一天行程。

* **13:45 - 15:00｜午餐：兼虎沾麵 博多 DEITOS 店（麵屋兼虎 博多デイトス店）**
  * **位置**：
    * 博多 DEITOS 2F「博多麵街道」。
  * **交通**：
    * 東急 Stay 博多 → 博多站，步行約 7～10 分鐘。
    * 進入博多站後前往 DEITOS 2F。
  * **推薦餐點**：
    * 濃厚沾麵。
  * **⚠️ 排隊提醒**：
    * 12/12 是星期六，午後可能需要排隊。
    * 建議最多抓約 **60～75 分鐘**。
    * 若排隊時間過長，直接改吃備案，不要影響後面的運河城行程。
  * **備案：雞肉屋源次郎 博多城店（かしわ屋源次郎 博多シティ店）**
    * **位置**：JR 博多城 9F「くうてん」。
    * **推薦餐點**：親子丼。
    * **餐點特色**：
      * 以雞肉、雞蛋及白飯為主。
      * 不含牛肉，也不是炸物。
      * 份量相對適中。
    * 若兼虎排隊時間太長，或當天不想吃太濃厚，可直接改吃此店。
  * **其他備案：馬屋 JR 博多城店（うまや JR博多シティ店）**
    * 可點炭火燒親子丼或雞肉炭火燒定食。

* **15:00 - 15:15｜前往 FUK COFFEE**
  * **交通**：
    * 博多站 → FUK COFFEE
    * 步行約 **10～15 分鐘**，方向正好往博多運河城移動。

* **15:15 - 15:55｜下午茶：FUK COFFEE**
  * **推薦餐點**：
    * 布丁。
    * 提拉米蘇。
    * 咖啡或其他飲品。
  * **建議停留時間**：
    * 約 **30～40 分鐘**。
    * 第一天若入境或 JR Pass 兌換稍有延誤，下午茶可縮短，不影響晚餐。
  * **下一站交通**：
    * FUK COFFEE → 博多運河城（Canal City Hakata）
    * 步行約 **5～10 分鐘**。

* **16:05 - 18:00｜博多運河城（Canal City Hakata）**
  * **行程**：
    * 逛博多運河城。
    * 欣賞水舞。
    * 角色商店及動漫周邊購物。
  * **購物重點**：
    * **JUMP SHOP 福岡店**
      * JUMP 系列動漫周邊。
    * **三麗鷗藝廊 博多店（Sanrio Gallery 博多店）**
      * 三麗鷗周邊。
    * **一番賞官方商店（一番くじ公式ショップ）**
      * 一番賞相關商品。
    * **萬代官方扭蛋店（GASHAPON BANDAI OFFICIAL SHOP）**
      * 扭蛋、角色小物。
  * **⚠️ 時間提醒**：
    * 晚餐已有固定時間，不建議逛到超過 **18:00**。
    * 若前面行程延誤，優先逛想買的角色商店，不需要把整座運河城逛完。

* **18:00 - 18:10｜步行前往晚餐餐廳**
  * **交通**：
    * 博多運河城 → **地雞屋 大和 本館**
    * 步行約 **2～5 分鐘**。
  * **備註**：
    * 餐廳距離運河城很近。
    * 逛完後直接前往，不需要另外搭車。

* **18:15 - 19:45｜晚餐：地雞屋 大和 本館（ぢどり屋 大和 本館）**
  * **料理特色**：
    * 以國產雞、地雞炭火燒及雞肉料理為主。
  * **推薦餐點**：
    * 地雞腿肉炭火燒。
    * 雞肉炙燒或其他熟食雞肉料理。
    * 烤蔬菜。
    * 雞肉小菜。
    * 白飯、茶泡飯或其他主食。
  * **生食提醒**：
    * 菜單若有雞肉刺身或半生雞肉，不想吃生食就不要點。
    * 可向店員確認雞肉 **充分加熱**。
  * **⚠️ 預約提醒**：
    * 12/12 是星期六。
    * 建議提前預約 **18:15 或 18:30**。
  * **⚠️ 店休提醒**：
    * 目前屬 **不定休**，不是固定星期六休息。
    * 建議 **12/10 再確認當週營業狀況**。

* **19:45 - 20:15｜返回飯店 Check-in、休息**
  * **交通**：
    * 地雞屋 大和 本館 → 博多站周邊 **東急 Stay 博多**
    * 步行約 **15～20 分鐘**。
  * **行程**：
    * 正式 Check-in。
    * 整理行李。
    * 洗澡休息。
    * 準備隔天 **12/13 門司港／下關／唐戶市場** 行程。

## 📝 12/13（星期日）Day 2：門司港、下關與唐戶市場

🎫 **票券：啟用【JR 北九州鐵路周遊券 3 日券】Day 1**

* **07:30 - 09:00 ｜ 前往門司港**
  * **交通**：博多站搭 JR 特急 Sonic 至小倉站，再轉 JR 鹿兒島本線至門司港站。
  * **備註**：使用 JR 北九州鐵路周遊券，勿搭新幹線。建議走人工通道出示 Pass。
  * **⚠️ 指定席提醒**：週日建議可事先劃 Sonic 指定席；不想被時間綁住也可搭自由席。

* **09:00 - 10:00 ｜ 門司港車站 ＆ 門司港懷舊區**
  * **交通**：門司港站周邊步行。
  * **行程**：門司港車站、舊門司三井俱樂部、藍翼橋、港邊散步拍照。

* **10:00 - 11:00 ｜ 關門連絡船前往下關 ＆ 赤間神宮**
  * **交通**：門司港碼頭搭關門連絡船至唐戶 / 下關，下船後步行約 10 分鐘至赤間神宮。
  * **行程**：赤間神宮參拜、拍照。
  * **備註**：關門連絡船現場買票即可，不用預訂。

* **11:15 - 13:00 ｜ 午餐：唐戶市場海鮮大餐**
  * **交通**：赤間神宮 → 唐戶市場，步行約 5 分鐘。
  * **推薦餐點**：握壽司、河豚、生魚片、炸物、海鮮熟食。
  * **⚠️ 排隊提醒**：12/13 是星期日，有週末限定「活きいき馬関街」。建議 12:00 前抵達，越早選擇越多，人也會很多。

* **13:00 - 16:30 ｜ 關門隧道人行道 ＆ 和布刈神社**
  * **交通**：唐戶市場 → 關門隧道人行道下關端入口，步行前往。走隧道回福岡縣門司端後，再步行至和布刈神社。
  * **行程**：縣界線拍照、和布刈神社、河豚御神籤。
  * **備註**：這段步行較多，建議穿好走的鞋。

* **17:00 - 18:30 ｜ 晚餐：門司港燒咖哩**
  * **交通**：和布刈神社周邊搭巴士或步行回門司港懷舊區。
  * **推薦餐廳**：伽哩本舖 或 BEAR FRUITS。
  * **⚠️ 排隊提醒**：燒咖哩名店通常不可預約，當天依排隊狀況決定吃哪間。

* **18:30 - 20:00 ｜ 返回福岡市區**
  * **交通**：門司港站 → 小倉站 → 博多站，JR 返回。
  * **行程**：回博多站後可簡單買宵夜，回飯店休息。

## 📝 12/14（星期一）Day 3：由布院童話村與烤雞皮神店

🎫 **票券：使用【JR 北九州鐵路周遊券 3 日券】Day 2**

* **09:00 - 11:30 ｜ 搭乘由布院之森前往由布院**
  * **交通**：博多站搭「特急 由布院之森」直達由布院站。
  * **⚠️ 訂票提醒**：由布院之森為全車指定席，需提前劃位。建議 2026/11/14 台灣時間 09:00 準時搶票。
  * **備註**：實際時間以 2026/12 JR 九州公布班表為準。

* **11:45 - 13:00 ｜ 午餐：由布まぶし 心**
  * **交通**：由布院站 → 由布まぶし 心 駅前店，步行前往。
  * **推薦餐點**：豐後牛釜飯、地雞釜飯。
  * **⚠️ 排隊 / 預約提醒**：熱門店，建議出發前 2～4 週確認是否可預約。若不能預約，抵達由布院後先去登記或排隊。
  * **⚠️ 店休提醒**：目前為 **不定休**，12/14 雖是星期一但不是固定公休日；建議 **12/10 再確認**。

* **13:00 - 15:30 ｜ 湯之坪街道 ＆ 湯布院花卉村**
  * **交通**：由布院站周邊、湯之坪街道全程步行。
  * **行程**：湯之坪街道、湯布院花卉村、甜點小吃、伴手禮。
  * **順路小吃**：
    * **Milch**：半熟起司蛋糕、布丁。
    * **telato**：抹茶義式冰淇淋。
    * **日本茶 5toku**：抹茶拿鐵、日本茶飲。
    * **金賞可樂餅 / 吉吾炸雞**：邊走邊吃。
  * **⚠️ 排隊提醒**：Milch、telato、熱門小吃可能排隊或售完，順路吃即可，不要每間都硬排。
  * **⚠️ 店休提醒**：Milch、telato 目前皆屬 **不定休**，不是固定星期一休；**12/10 再確認 12/14 是否正常營業**。

* **15:30 - 16:30 ｜ 金鱗湖漫步**
  * **交通**：湯之坪街道 → 金鱗湖，步行前往。
  * **行程**：金鱗湖散步、拍照。
  * **備註**：12 月由布院偏冷，注意保暖。

* **17:00 - 19:20 ｜ 返回博多**
  * **交通**：由布院站搭特急由布號 / 由布院之森回博多站。
  * **⚠️ 指定席提醒**：回程建議與去程一起劃位。晚餐有預約時，不要訂太晚的回程。

* **20:00 - 21:30 ｜ 晚餐：かわ屋 祇園店**
  * **交通**：博多站 → かわ屋祇園店，步行約 10～15 分鐘；或搭地下鐵至祇園站。
  * **推薦餐點**：烤雞皮串、串燒、居酒屋料理。
  * **⚠️ 預約提醒**：目標 **20:00 或 20:15**，不要訂太早，避免由布院回程延誤。
  * **預約方式**：線上預約主要開放 **17:00～19:00**；本行程目標時間超過線上時段，建議 **11 月中下旬直接電話詢問 20:00 訂位**。
  * **備案**：若電話無法訂位或當日滿席，就改吃博多站／祇園周邊其他雞肉串燒或居酒屋。

## 📝 12/15（星期二）Day 4：太宰府與水炊鍋

🎫 **票券：使用【JR 北九州鐵路周遊券 3 日券】Day 3**

* **08:30 - 09:15 ｜ 前往太宰府**
  * **交通**：博多站搭地下鐵至天神站，步行至西鐵福岡（天神）站，搭西鐵天神大牟田線至西鐵二日市站，再轉乘至太宰府站。
  * **備註**：這天主要使用地下鐵與西鐵，JR Pass 使用較少。
* **09:30 - 11:00 ｜ 竈門神社**
  * **交通**：太宰府站搭社區巴士 Mahoroba 號前往竈門神社。
  * **行程**：竈門神社、授與所、御守。
  * **備註**：天氣不好或想走輕鬆版，可刪掉竈門神社，直接逛太宰府表參道。
* **11:00 - 12:00 ｜ 午餐：一蘭 太宰府參道店**
  * **交通**：竈門神社搭巴士回太宰府站 / 表參道。
  * **推薦餐點**：太宰府限定合格碗拉麵。
  * **⚠️ 排隊提醒**：不可預約，11:00 左右先去比較好。若排太久，改吃表參道小吃。
* **12:15 - 14:30 ｜ 太宰府天滿宮 ＆ 天開稻荷神社**
  * **交通**：太宰府表參道步行前往太宰府天滿宮，再步行至天開稻荷神社。
  * **行程**：太宰府天滿宮、御神牛、太鼓橋、天開稻荷神社。
* **14:30 - 16:00 ｜ 太宰府表參道小吃**
  * **交通**：太宰府天滿宮 → 表參道 → 太宰府站方向，沿路步行逛街。
  * **建議動線**：太宰府天滿宮 → 表參道一路吃 → 茶和々 → 太宰府站。
  * **順路小吃**：
    * **天山太宰府ぷりん店**
      * 推薦：太宰府布丁。
    * **梅枝餅 安武**
      * 推薦：現烤梅枝餅。
    * **かさの家**
      * 推薦：梅枝餅。
    * **星巴克太宰府天滿宮表參道店**
      * 建築拍照、咖啡。
    * **茶和々（SAWAWA）太宰府店**
      * 中文：太宰府抹茶甜點專門店。
      * 推薦：**濃抹茶冰淇淋**。
      * 特色：有不同濃度的抹茶冰淇淋可選，喜歡濃郁抹茶可以挑較高濃度。
      * 地點：太宰府表參道靠近太宰府站一側，綠色店面很好認。
      * 地址：福岡縣太宰府市宰府 1-14-27。
  * **⚠️ 排隊提醒**：
    * 梅枝餅名店可能排隊，若安武或かさの家排太久，可改買其他家。
    * 小吃不用每間都吃，可依當天排隊狀況、食量挑選。
    * **茶和々建議最後再吃**，因為位置靠近太宰府站，吃完剛好準備回福岡市區。
* **16:30 - 17:30 ｜ 返回福岡市區**
